位置对比

把对抗路 / 打野 / 中路 / 发育路 / 游走五条分路放在一起：默认展示前 3 条，可自选 2–4 条。 每条分路的值 = 当前数据范围内该位置全部选手按出场局数加权聚合（等价于「该分路所有局」的合计口径）。 边界：五种分路职责不同，KDA / 输出占比的天然区间就不一样，因此只读作「分路画像」，不能直接当成强弱排名；虚线为跨分路加权均值，仅作形状参考。 想看具体某名选手？用 「选手对比」； 想看战队 / 英雄？用 「战队对比」 / 「英雄对比」。

口径说明
1. 分路归属按选手在该范围内的实际出场位置字段，位置未知的选手不计入任何分路；
2. 每条分路的指标按选手出场局数加权平均，等价于「该分路全部局」的合计口径，不是「选手平均」；
3. 不同分路职责不同（游走参团高、发育路输出高、打野 KDA 高），雷达与表格的原始值不可跨分路直接比强弱；
4. 预计聚合样本为该范围内出场达标的选手；候选数不足的分路会直接缺席，不会用缺失值填充。
