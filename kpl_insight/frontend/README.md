# 项目默认前端

本目录包含峡谷有数的 HTML、CSS、JavaScript、第三方前端库与已归档展示数据，随项目一并提供。无需 Node、前端构建、模型权重或安装研究环境。

在项目根目录执行 `python start.py`，或 Windows 下双击 `启动网站.bat`。启动后自动打开浏览器；按 Ctrl+C 停止。使用 `python start.py --port 8001` 更换端口，`--no-browser` 只启动服务。

已安装公开版工具的用户也可运行 `python -m kpl_insight`（默认打开网站）或 `python -m kpl_insight web --port 8001`。

页面通过 HTTP 请求读取本目录下的静态数据，请勿直接双击 HTML。服务默认仅监听本机地址，提供的文件范围限于前端目录。可以直接修改页面和 assets 内的样式、脚本；`bundle-manifest.json` 记录打包时的文件与校验值。

使用 localhost 或 127.0.0.1 访问时，页面只显示“一键启动 / 停止”和运行状态。点击启动后自动按本地赛程选择当前或下一项赛事：有模型时启动采集、预测与网页数据导出；没有模型时自动仅采集，并明确标注未生成预测。无需填写赛事 ID、选择模式或输入命令。异常详情默认收起，仅在需要排查时显示。

控制按钮需要通过 `python start.py` 或“启动网站.bat”打开本地网站。页面每 5 秒刷新状态；关闭标签不会停止服务，按停止按钮或在终端按 Ctrl+C 正常退出可停止本面板任务。线上域名不显示面板，也不请求本地接口。采集依赖与有效模型仍需在本地环境中准备，网站不会自动安装依赖或训练模型。

这些数据是打包时的归档快照。启动网站不会自动启动比赛采集、模型训练或实时预测；实时能力需要单独配置相应工具。部分第三方头像、图标与录像仍需联网。数据、商标和第三方库保留各自权利，Three.js 的许可见 `assets/vendor/`。

开发者更新内置前端：在开发仓运行 `python tools/publish/bundle_frontend.py --source <网站源码目录>`；公开发布准备流程会同步这份前端。同步只复制网页和允许类型的 assets，不包含网站仓库的 Git、部署配置和本地工作目录，不删除现有文件。
