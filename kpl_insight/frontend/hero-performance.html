口径说明
1. 系列赛 = 一次双方 BO 对抗；选手 × 英雄 × 系列赛为一条证据行，单局只作为系列赛内的事实；
2. P50 / P75 / P90 是同期同位置同英雄的描述性参考线，不是官方评级；样本池排除当前选手；
3. 同赛事池不足 3 人 / 20 局时，显式回退到同位置同英雄全历史，并标注“基准已扩大”；仍不足则停止评级；
4. 每分钟伤害 / 经济只除以该字段有效的出场分钟；源数据里伤害 / 经济为 0 视为缺失，不按 0 摊薄；参团率按有效出场局数加权，队内 0 击杀时无定义；
5. 单系列赛 1 局 0% / 100% 只展示事实；变化结论至少需要 6 个系列赛，且仍只作描述，不作因果；
6. 当前覆盖 2019–2026 站内历史；2016–2018 外部历史尚未接入本页，避免把不完整字段混入同一基准池。
