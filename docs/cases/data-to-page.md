# 真实数据如何变成页面中的分析结果

> 使用 2026-06-26 北京 JDG 对广州 TTG 第 3 局，第 767 秒的留存材料。这里公开的是最小聚合字段摘录，不是完整接口响应、训练数据集或可独立重建模型的特征全集。

## 一、接口响应：先取得记录，而不是先写结论

[真实片段 JSON](../examples/real-snapshot-excerpt.json)仅保留游戏时间、比赛状态及双方战队级经济、击杀和防御塔计数。请求标识、请求头、账户信息、选手明细、BP、媒体地址和其他响应内容均未纳入。

摘录保留原字段名：

```json
{
  "game_duration": 767448,
  "status": 1,
  "win_camp": 0,
  "camp1": {
    "team_name": "广州TTG",
    "gold": 41930,
    "kill_num": 8,
    "push_tower_num": 6
  },
  "camp2": {
    "team_name": "北京JDG",
    "gold": 37633,
    "kill_num": 4,
    "push_tower_num": 2
  }
}
```

该记录的 `game_duration` 使用毫秒。这个状态下比赛仍在进行，`win_camp = 0` 不是平局，也不是最终标签；赛果在另一个结果记录中核对。

## 二、字段整理：时间、身份和单位先统一

对应[解析实现](../../kpl_insight/core.py)中的 `parse_snapshot`：

- 游戏时间转换为整数秒：767448 // 1000 = **767 秒**。
- 精确分钟约为 12.7833；页面显示可四舍五入为 **12.8′**。
- 当前特征构建中的 `minute_bin` 为 **12**，不是页面四舍五入后的 13。
- 固定本局 camp1 为 TTG、camp2 为 JDG；跨局或大场展示时再按真实战队身份对齐。

本摘录不包含全部字段。被省略的字段不表示零；不能把这段最小 JSON 当作完整快照送入生产模型。

## 三、特征构建：让统计变成模型可使用的量

以下是当前[特征构建](../../kpl_insight/core.py)中能由公开片段直接核对的部分：

- `gold_diff`：41930 − 37633 = **4297**。
- `tower_diff`：6 − 2 = **4**。
- `gold_diff_per_min`：4297 / 12 ≈ **358.0833**。
- `kill_diff_per_min`：(8 − 4) / 12 ≈ **0.3333**。
- `gold_ratio`：4297 / (41930 + 37633) ≈ **0.0540075**。

趋势特征还需要此前快照，分路特征需要选手数据，战队先验需要此前比赛。单张摘录不能恢复这些输入，也不能重建当时全部特征。这里核对的是当前选定字段的转换逻辑，不保证历史模型使用了完全相同的特征版本。

## 四、模型输出：读取历史记录，不假装重新推理

相同游戏时间的历史预测记录保留：

```json
{
  "snapshot_time_sec": "767",
  "minute": "12.78",
  "lag_sec": "60.0",
  "camp1_win_prob": "0.94804",
  "camp2_win_prob": "0.05196",
  "gold_diff": "4297",
  "kill_diff": "4",
  "tower_diff": "4"
}
```

**这不是由上面五个特征现算出的概率。** 概率来自已经保存的预测 CSV，所选行没有模型版本和指纹字段，因此不把它命名为“当前 V12 的输出”，也不据此推断历史权重。

原始响应与预测记录的游戏时间和上述聚合差值一致，但采集墙钟时间不同。样例保留来源说明，便于理解对齐范围；它不证明捕获到了生成预测的同一个 HTTP 响应包。

## 五、导出展示：精度与方向需要明确

已有站点复盘文件中的对应时点将分钟和概率精简为：

```json
{
  "m": 12.8,
  "p": 0.948,
  "gd": 4297,
  "k": [8, 4],
  "t": [6, 2]
}
```

这里 `p` 是本局 camp1 的概率，页面可显示为 94.8%；若改成 JDG 视角，应显示其补数约 5.2%。大场首页的队伍顺序不能直接代替本局 camp1 / camp2。

页面摘要、展示层平滑和当前重放还可能采用不同口径，不应把所有界面数字都称为未经处理的原始模型输出。

本地页面中，该采样点的选手经济汇总为 41,861 与 37,618，与原始战队聚合值 41,930 和 37,633 并不完全一致；页面保留的金差 4,297 来自战队聚合口径，不能由这两项选手汇总直接相减复算。这一差异提示仍需检查字段来源与采样对齐，本例不声称整个页面所有字段已完全一致，也不据此改写原始记录。

## 六、无需联网的最小核对

在公开数据与模型仓库根目录运行：

```bash
python tools/verify_walkthrough.py
python -m unittest discover -s tests -p "test_walkthrough_sample.py" -v
```

脚本检查时间、身份、差值、概率补数与页面取整，并计算这一个时点的概率误差。不需要安装模型依赖或下载权重；它**不训练模型、不复现完整推理，也不验证总体准确率**。
