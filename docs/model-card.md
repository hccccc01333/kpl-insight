# 局内胜率模型

本项目把胜率作为数据研究的一部分。模型输入来自当前及此前的局面，输出 camp1 获胜概率；它不是官方胜率，也不保证单局结果。

## 实现与产物

入口为 `kpl_insight/models/train.py`。当前实现沿用 V12 早期/中后期专家混合、分阶段校准和经济一致性护栏；`train_v9_model` 与 `v9_official_platform.joblib` 的旧名称为兼容保留。以产物中的 `version`、`model_name`、`trained_at` 和特征列为准。

训练结合真实快照和终局缩放辅助样本。辅助样本不是还原的比赛过程；测试应使用真实快照，并标明覆盖范围。公开仓库不附带私有训练数据或预训练权重。

## 数据隔离

真实局按时间排序，整局划分为 train / calibration / test。校准器、裁剪参数和相关选择只使用校准段；测试段只报告指标。同一局不能按帧随机分到不同集合。由终局生成的辅助样本也须排除校准和测试局。

战队先验按历史时间构造。评估还需关注赛事与版本变化、样本选择、低频战队、翻盘局和早期局面；时间隔离本身不能消除所有偏差。

## 指标与解释

报告 Brier、校准误差、AUC、准确率及分阶段/逐局结果，并同时报告局数、切片数、测试局 ID 和模型指纹。多个相关快照不能当作独立比赛来夸大样本规模。

此源码发布不包含一份可复现验证的真实测试数据和权重，因此 README 不列历史准确率作为当前性能承诺。合成演示通过仅代表软件流程可运行。

直播存档、当前模型重放、展示层平滑属于不同口径。输入摘要不是因果归因，资源窗口是基于历史样本的估计，不保证是当前版本官方刷新时间。

## 可核对的实例

[验证方法与失败案例](cases/model-validation-and-failure.md)保留了一次没有兑现的高概率判断，并单独说明历史内部诊断的样本范围和外部复现限制。[真实字段转换实例](cases/data-to-page.md)及其离线核对脚本只验证最小摘录的算术与记录对齐，不重建模型，也不验证总体准确率。
